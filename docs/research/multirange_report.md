# Мультидиапазонность + прямая модель (плотность+melt=2) — отчёт

Стенд `analyze_multirange.js`, test 2024-25 (267 строк). Прямая den = G0=0.45, g=1, c=1.5, melt=2
(эпохи T≥0, слои под настом защищены). Контроль: та же мультидиапазонная логика на внедрённой
KN=0.60+старение. Параметры прямой модели НЕ оптимизировались. Пороги tol = 0.5 / 1.0 / 2.0 см.

**⚠️ Ограничение данных:** в test 2024-25 КАЖДЫЙ возраст имеет n<50 (0:43, 1:28, 2:23, 3:20,
4:18, 5:15, 6:13, 7:16, 8:16, 9:15, 10:20, 11:12, 12:8, 13:14, 14:6) — результаты по отдельным
возрастам слабые; агрегаты 0-2 (n=94) и 3-7 (n=82) приемлемы. Сказано.

## Вердикт по критериям ШАГ 6
1. **Coverage выше?** Да, у прямой выше, чем у контроля (68.5% vs 43.8% при tol=1) — но ценой
   ширины (ниже).
2. **Диапазоны уже?** НЕТ — у прямой в **2.8 раза ШИРЕ** (8.41д vs 2.95д при tol=1; 4.90 vs 2.19
   при tol=0.5). Гипотеза «прямая точнее → диапазоны уже» не подтвердилась: кривая плотностной
   модели с таянием более пологая → H пересекается медленно → диапазоны шире.
3. **Recall 0-2 не хуже?** НЕТ — «0-2 покрыт» у прямой 84-87% vs 96.8% у контроля и 96% у
   эталона-argmin; MAE 0-2 прямой-argmin 1.7 (vs 0.723).
4. **Однозначность:** у прямой 45-62% замеров дают 2+ диапазона (cov на них 51-84% — часто
   реальный возраст НИ в одном); у контроля 0.0% (267/267 однозначны). Для бота это хуже:
   неоднозначный ответ.

## Вывод
**«Не подтвердилось».** Прямая модель + мультидиапазонность НЕ даёт лучшей точности, чем текущая
обратная: coverage выше только за счёт в 2.8 раза более широких диапазонов, recall 0-2 ниже
(84-87% vs 96%), а 45-62% ответов неоднозначны (2+ диапазона). Внедрение НЕ предлагается.

Побочный вывод: у ВНЕДРЁННОЙ модели мультидиапазонность почти всегда однозначна (267/267 при
tol≤1) и «0-2 покрыт» = 96.8-98.9% — текущая модель уже даёт хорошее покрытие свежих следов;
плотностная её не улучшает. tracker-tool.js не менялся, коммитов нет.
