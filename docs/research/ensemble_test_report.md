# Полный рандомизированный тест ансамбля V1 (среднее H0=0.75 + влажность) — отчёт

Стенд `analyze_ensemble_test.js`, test 2024-25 (267 строк, 93 цепи). Одиночные модели не тронуты,
параметры не оптимизировались. После фикса двух багов (ключи permutation; пустой 15+).

## ШАГ 2. Permutation (1000 итер., попарный swap ответов V1/одиночной по замерам)

## ШАГ 4. Вывод (по критериям задачи)
**Оба формальных критерия НЕ выполнены:**
1. Bootstrap 95% ДИ **включает 0** (и для A, и для B) → выигрыш не значим.
2. Permutation p = 0.429 / 0.350 (3-7) и 0.075 / 0.187 (all) → **p ≥ 0.05** → не значим.

→ **V1 статистически НЕ значим. Выигрыш (2.659 vs 2.683) в пределах шума. НЕ внедрять — оставить
модель как есть.**

Честные нюансы (не меняют вердикт):
- Знак устойчиво в пользу V1 (64-90% bootstrap-итераций лучше), эффект концентрируется на 10-14
  (89.9%, ДИ касается 0; p(all vs A)=0.075 — вблизи порога).
- 10-14 — диапазон, где ВСЕ модели плохи (MAE ~10.4 см); относительный выигрыш V1 там 0.5% —
  практической ценности не имеет.
- Не внедрять = tracker-tool.js остаётся без изменений, одиночные модели и патчи «не знаю»
  не тронуты, коммитов нет.
