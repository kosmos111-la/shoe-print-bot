## Коммит 2: фикс /calc_weather (429 Open-Meteo)

После коммита 1 выяснилось (по логу бота `Request failed with status code 429`),
что `/calc_weather` выбивает лимит запросов Open-Meteo: на одну команду уходило
**7–8 отдельных запросов**, а бесплатный тариф лимитируется на IP. Исправлено в
`modules/calculators/weather-service.js`:

- **7–8 запросов → 2** к Open-Meteo (`getForecastBundle`: current+hourly+daily+восход/закат
  одним запросом; `getArchiveBundle`: история+осадки+снег одним запросом; +1 геокодинг).
- **`fetchWithRetry`**: ретраи с паузой на 429/5xx; при устойчивой перегрузке —
  понятное сообщение «Сервис погоды временно перегружен (429), попробуйте позже».
- **`getSnowData`**: убран `snow_depth` — архивный API отвечает на него 400
  (`Cannot initialize ForecastVariableDaily from invalid String value snow_depth`),
  из-за чего данные о снеге были всегда пустыми. Теперь `snowfall_sum` доходит до графика.
- **`getLocationName`**: обратный геокодинг через BigDataCloud (без ключа, русская
  локаль) — Open-Meteo `/v1/search` принимает только `name` и на `lat/lon` отвечает 400,
  поэтому название города показывалось как координаты.

Проверено: 3 запроса на команду, полный отчёт (текущая, 6 ч, 2 дня, 7 суток со снегом,
восход/закат), `test-tracker-js` 137/137, smoke OK, `test-epochs-js` OK.

Если 429 будет повторяться часто (очень много пользователей за одним IP) — следующим
шагом можно добавить кэширование погоды на 5–10 минут на точку.

## Коммит 3: кэш погоды + паузы на 429

429 держался даже после ретраев — бесплатный тариф Open-Meteo лимитируется **на IP**
(600/мин, 5 000/час, 10 000/сутки), и на общем/операторском IP лимит выбивается.
Добавлено в `weather-service.js`:

- **Кэш результата `/calc_weather` на 10 минут на точку** (ключ — координаты с
  точностью 4 знака): повторный запрос той же локации **не ходит в сеть вообще**
  (проверено: 1-й запрос = 3 вызова, 2-й запрос той же точки = 0 вызовов).
- **Паузы на 429/5xx увеличены** до 2,5 с / 5 с (для кратковременных всплесков).

Что важно понимать: если лимит уже исчерпан на IP, ретраи не помогут — окно сброса:
почасовое — в начале часа, суточное — в полночь UTC. С кэшем бот тратит на порядок
меньше запросов. Для гарантированной ёмкости (много пользователей) — платный тариф
Open-Meteo (API Standard, `customer-api.open-meteo.com` + `&apikey=`); данные Open-Meteo
требуют атрибуции (CC BY 4.0).
