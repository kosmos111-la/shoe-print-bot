### Ключевые установленные факты
1. **«суточный» ≈ осадки за сутки** (корр. 0.86–0.95) — свежий снег, одинаков для всех следов дня;
2. **глубина снега в следе (см) — то, что меряют линейкой**: колонка I на строке «вечер»
   (ежедневный ряд референс-следа) + «в следе» в колонках следов (полно в 2022-23, фрагментарно позже);
3. **«След 1» — референсный след** (110–112 дней/сезон), остальные следы 2–16 — по 1–31 дню,
   След 17+ замеров почти не имеют;
4. глубина без учёта снегопадов НЕ отделяет возраст: без нового снега глубина ~0.4–0.8 см
   и обнуляется к 7-му дню; с новым снегом растёт (0.9→4.4→8→10→15 см);
5. серии «Оседание пухляка» — 5 следов × 22 дня: 13→7.3, 8.9→4.2, 15.4→7.7, 11.6→8.9, 2.6→2.4 см;
6. «Растения» — качественный текст, численно непригодны.

## 2. Чего не хватает (данных нет — зафиксировано явно)
- **Плотности снега нет вообще**: поиск «плотн/масса/вес» по всей книге — 0 вхождений.
  Есть только толщины (глубина следа, глубина пухляка, снежный покров). ⚠️ Ограничение;
- **давление и точка росы** в листах «Пухляк» не записаны (есть в «зимние оледенение»/«глубина следа»);
- **замело/заметает** в «Пухляк» не фиксировалось (флаг = 0 во всех строках snow_long);
- глубина референс-следа в 2022-23 начинается только с 02.02.2023 (первые 7 дней — пропуск);
- в тестах калькулятора 15.02.24 дни 12–14 — без фактических замеров; «Растения +» — пустой лист;
- категория 8+ по полноте хуже всех (73% с глубиной, 65% с погодой И глубиной);
- отдельной серии «пластина сдвига» внутри листов «Пухляк» нет — см. вопрос (б) ниже.

## 3. Что можно восстановить
- **5 текст-чисел** в «глубина следа» («0.3»×4, «0.5») → числа (машинная правка);
- **6 мультизначений** в «осадки к пухляку» («0,25 1 1,25» и т.п.) — три варианта перевода,
  нужен выбор правила (брать первое значение? среднее?);
- **~1100+ ошибок формул** (#DIV/0! в «Оседание» — снег стаял; #DIV/0!/#REF!/#NUM! в
  статистических блоках «Пухляк*» и колонках отношений) — при сборке выборки исключаются,
  часть чинится (деление на 0 → пусто); в сырых ячейках наблюдений ошибок НЕТ;
- «суточный» можно восстановить как осадки, накопл = накопленная сумма суточных;
- возраст следа восстанавливается из дат постановки/замера (что и сделано в snow_long).

## 4. Готовность к модели (давность по глубине + погоде)
**Частично готово.** Что есть: 1693 наблюдения, 112 следов, глубина+погода, флаг нового снега,
возраст. Что критично:
- per-track серий глубины мало (только 2022-23: 41 след с ≥5 замерами; 2023-24: 32; 2024-25: 18);
- разделимость категорий по одной глубине — слабая (перекрытие p25–p75 у 3-7 и 8+),
  нужен контекст осадков; без нового снега сигнал «>7 дней» = глубина ≈ 0;
- плотности нет — модель «давность по глубине» строить можно, «по плотности» — нельзя.

## 5. Рекомендации
1. **Категории**: вариант B — **0-2 / 3-7 / 8+** (381/411/582 наблюдений с глубиной) вместо
   исходных 0-1/2-3/4-7/8+ (271/205/316/582 — тонкие первые две);
2. **обязательно** использовать осадки/флаг нового снега как вход модели — без этого глубина
   не отделяет возраст;
3. **дособирать**: регулярные замеры глубины по всем следам (не только референсному) хотя бы
   7–10 дней, фиксацию замело, плотность снега (весы/керн) — хотя бы в 1–2 сезонах;
4. кодировать состояния «Растений» в категориальную шкалу (для методики «маркер→давность»);
5. тест-калькулятор: добавить температуру/ветер в формулу (сейчас фикс. 0.92 см/мм и 0.75/день,
   из-за чего в морозные/ветреные дни ошибки до +7 см);
6. вести протокол: единая раскладка колонок по сезонам (E=солнце в 2022-23/2023-24, но E=температура
   в 2024-25 — источник ошибок парсинга).

## Ответы на контрольные вопросы

### (а) Какая колонка в «Пухляк» — то, что поисковик меряет линейкой в поле?
**«в следе»** — глубина рыхлого снега в следе, см:
- значения в колонках следов (J, K, …) на строках с меткой **«в следе»** (строка «день») —
  в 2022-23 заполнены по каждому следу (След 1: 6.0 → 6.5 → 6.0 → 5.8 …);
- и **колонка I на строке «вечер»** — ежедневный ряд глубины референс-следа
  (2024-25: 11.6 → 14.6 → 14.6 → 13.5 → 12.5 → 17.8 …).
«суточный» (строка «ночь») — это не замер линейкой, а свежевыпавший снег (≈ осадки, корр. 0.86–0.95).

### (б) Есть ли отдельные серии «пластина сдвига» или только «Пухляк» без пластины?
**Отдельная серия есть**: лист **«Пластина зимний след»** — 16 сессий (2022-23), качественные
маркеры «Пластина образуется в утрамбованном снегу / в сугробе» (да/нет) + погода. Плюс близкие
листы «зимние оледенение следа» и «глубина следа» (колонки «лед», «след в снегу да/нет/бугорок»).
Листы **«Пухляк»** фиксируют только рыхлый снег (пухляк) — **пластина в них не измеряется**
(нет колонок/меток «пластина»).

### (в) Есть ли измерения плотности снега или только толщина?
**Только толщина.** По всей книге нет ни одной записи плотности, массы или веса снега
(поиск «плотн/масса/вес» — 0 вхождений). Есть: глубина в следе (см), глубина пухляка (см),
глубина снежного покрова, потери снега в % (производные от толщины). **Плотность снега —
ограничение данных**: модель «давность» можно строить только по глубине + погоде,
плотностные признаки недоступны.
