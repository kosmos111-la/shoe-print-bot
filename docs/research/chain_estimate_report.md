# Цепочечная (оконная) оценка возраста по двум замерам — отчёт

Дата: 2026-11-12. Модель не менялась (`analyze_chain_estimate.js`, k=0.0264 фикс).
Пары замеров одного следа с интервалом L суток. Истинный возраст = возраст второго замера (t2).
- **Построчно**: t* = argmin_{t∈0..30} |f(t2−t→t2) − H2| (только последний замер).
- **Совместно**: t* = argmin_{t∈L..30} |f(t2−t→t1) − H1| + |f(t2−t→t2) − H2| (оба замера;
  корректная нижняя граница t ≥ L — след существовал на первом замере).

## ⚠️ Уточнение прошлой цифры
В отчёте windows_final «0.4–0.6 дня» использовалась ошибочная нижняя граница t ≥ t2
(она запрещала все занижения возраста и завышала точность). С корректной границей t ≥ L
выигрыш меньше, но **остаётся большим и реальным** (см. таблицу).

## Вывод по порогу (< 1.0 дня для 3-7)
- **Подтверждается при интервалах L ≥ 5** (холдаут: 0.45–0.97; на train с большими выборками
  < 1.0 с L ≥ 6: 0.94, n=103).
- Для **реалистичного протокола (второй визит через 2–3 дня, L=2–3)**: 3-7 MAE 1.27–1.74
  на холдауте — **вдвое лучше построчной (2.56–2.70)**, но не < 1.0.
- Механизм реальный: замер H1 на первом визите фиксирует раннюю эволюцию следа и «прибивает»
  дату рождения; чем длиннее интервал, тем больше информации (ошибка монотонно падает с L).

## ШАГ 3. Как встроить в бота/протокол
- Сейчас `estimateChain` (tracker-tool.js:243) — это несколько следов в ОДИН визит: берётся
  минимум глубин и вызывается обычный `estimateAge` (построчный обратный ход). **Повторного
  замера того же следа в другой день в боте нет.**
- Протокол v5 уже поддерживает идею: флаг «след виден (да/нет/—)» позволяет опознать ТОТ ЖЕ
  след при возврате; в данных есть колонка «возраст_последнего_измерения»; «Дневник» хранит
  цепочки дней.
- Предложение (НЕ реализовано, модель не трогаем): новая функция `estimateAgeJoint(сезон,
  дата1, H1, дата2, H2)` — тот же forward (k=0.0264), но argmin по двум замерам. Протокольная
  добавка: «при повторном визите к тому же следу через 2–5 дней укажите дату и глубину первого
  замера»; бот хранит пару (дата, глубина) в дневнике/сессии.
- Ожидаемый эффект при L=2–3: 3-7 MAE ≈ 1.3–1.7 (вместо 2.7); при L=5–6: < 1.0.

## Итог
Направление **подтверждено**: цепочечная оценка даёт реальный и большой выигрыш (3-7 MAE
вдвое-втрое меньше), порог < 1.0 достигается при интервале ≥ 5 дней. Это первая подтверждённая
гипотеза за сессию. Дальнейшие шаги — по вашему решению: (а) реализация estimateAgeJoint +

на новых данных. Модель и константы НЕ меняются.
