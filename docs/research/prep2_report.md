## Вывод: пригодность сезонов
- **2022-23 — обучающий**: длинные непрерывные серии (медиана 11 дней), 40 следов ≥5 дней,
  все 52 следа с замерами. Единственный сезон с полноценной траекторией «свежий → старый» по каждому следу.
- **2023-24 — обучающий с оговоркой**: 31 след с серией ≥5 дней (312 строк) — достаточно для
  обучения, но 62 следа — лишь 1–2 замера (годятся только как «точечные» примеры категорий).
- **2024-25 — только валидация/тест**: 17 следов ≥5 дней, медиана серии 1 день; как самостоятельный
  обучающий материал — недостаточен.
- Рекомендация для сплита: **обучение на 2022-23 (+ серии ≥3 дней из 2023-24), тест на 2024-25**
  (и/или короткие следы 2023-24) — см. шаг 6.
