# Шаг 3. Сборка long-таблицы снега (snow_long.csv)

## Что сделано
Из трёх листов «Пухляк», «Пухляк 2023-2024», «Пухляк 2024-2025» собрана длинная таблица
наблюдений по следам. Одна строка = одно наблюдение одного следа в один день
(только по реально записанным в книге значениям — пустые пары (след, день) не добавлены).

## Соответствие колонок книги → полям таблицы (установлено в ходе аудита)

| Колонка книги | Содержимое | Поле в snow_long.csv |
|---|---|---|
| B='Дата', C=дата | заголовок суточного блока, дата | дата_замера |
| C (строки «ночь/утро/день/вечер») | период суток | — |
| D | ветер, м/с | ветер (значение строки «день») |
| E | солнце (качественная, «нет»/«дождь») | не переносится (качественная) |
| F | температура, °C | температура_день (строка «день»), температура_ночь (строка «ночь») |
| G | осадки, мм | осадки_мм (сумма за сутки по 4 периодам) |
| H | влажность, % | влажность (строка «день») |
| I (строки «ночь/утро/день») | метки «суточный»/«накопл»/«в следе» | — |
| I (строка «вечер») | измеренная глубина рыхлого снега в следе, см | daily_в_следе_см (референсный ряд) |
| J, K, L, … (колонки треков) | значения трека: «суточный» (ночь), «накопл» (утро), «в следе» (день) | суточный_мм, накопл_мм, глубина_см |

Ключевые факты о данных (подтверждены численно):
- **«суточный» ≈ сумма осадков за сутки** (корр. 0.86–0.95 по сезонам) — это свежевыпавший снег,
  одинаковый для всех треков данного дня (физически так и есть);
- **глубина снега в следе (см) — это то, что меряется линейкой**: колонка I на строке «вечер»
  (ежедневный ряд, растёт со снегопадом, оседает между снегопадами) и значения «в следе»
  в колонках треков (в сезоне 2022-23 — по каждому треку, в 2023-24/2024-25 — фрагментарно);
- **«След 1» — референсный трек**: ведётся весь сезон (110–112 дней), остальные треки 2–16
  — по 1–31 дню, далее (След 17+) наблюдения почти отсутствуют.

## Явно отсутствующие данные (не выдуманы)
- **давление и точка росы** — в листах «Пухляк» таких колонок нет (есть только в листах
  «зимние оледенение следа»/«глубина следа»): поля оставлены пустыми, в таблицу не включены;
- **замело_флаг**: в «Пухляк» записи «замело»/«заметает» отсутствуют (такие пометки есть в
  других листах), флаг = 0 во всех строках;
- **глубина референсного трека в 2022-23**: ежедневный ряд I-вечер начинается только с 02.02.2023,
  первые 7 дней референс-трека глубины нет;
- треки След 17+ (2022-23) и След 17+ (2023-24/2024-25) реальных замеров почти не имеют —
  замеры шли только по След 1..16.
