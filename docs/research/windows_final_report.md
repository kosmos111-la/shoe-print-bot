# Финальная проверка двухфазной модели на всех окнах L=2..10 — отчёт

Дата: 2026-11-12. Модель не менялась. Методика: «скользящее окно» = пара замеров одного
следа с разницей ровно L суток (H1 на возрасте t1, H2 на t2=t1+L). Оценка — **совместный
обратный ход**: t* = argmin_{t≥t2} [|f(t2−t→t1)−H1| + |f(t2−t→t2)−H2|], истинный возраст = t2.
train = 2022-23+2023-24, test = 2024-25. `analyze_windows_final.js`.

L=2,3,6,9,10 — равна; L=4,5,7,8 — двухфазная лучше на 0.03–0.05 дня (L=7,8 при n<50 —
ненадёжно; L=4,5 — в пределах шума). Выигрыша «структуры двух фаз» нет ни для одного L.

## ШАГ 4. k_fast по эпохам
Все 4 эпохи = 0.005 (разброс 1.0×) для всех L, кроме L=4 (вечер=0.0264, 5.3×) — это артефакт
плоской области (все значения сетки дают почти одинаковый MAE; «разброс» случайный), тестовый
выигрыш 0.39→0.37 при n=79 — шум. По ограничению: **«сглаживание не влияет»** (для всех L).

## ШАГ 5. Холдаут
Двухфазная не лучше однофазной k_ref=0.004 ни для одного L (равна или +0.03–0.05 в пределах
шума). Бонус-факт: сама оконная оценка (два замера) точнее построчной в разы (0.4–0.6 дня
против 2.7 для 3-7) — это свойство «цепочки», не двухфазной модели.

## ШАГ 6. Вывод — тему ЗАКРЫВАЕМ
1. Двухфазная модель **не даёт выигрыша ни для одного L** (2..10): её «лучший» вариант —
   вырожденная однофазная с низким k на краю сетки; против однофазной k_ref=0.004 — паритет
   или шум.
2. Паттерн «низкий k лучше» — уже четвёртый раз (k_slow=0.001, сдвиг окна, k_ref=0.004,
   здесь 0.005/0.001), но на построчных холдаутах он не переносится (2023-24: 2.76–2.78,
   2024-25 3-7: 3.01 — хуже). Константы НЕ меняем.
3. k_fast по эпохам не различается → калибровка по средним не виновата в отсутствии эффекта.
4. r02 (L=2): baseline 0.86 → двухфазная 0.82 (лёгкое проседание, шумового уровня).

**Решение: оставляем однофазную модель как есть (k_ref=0.0264), двухфазную тему закрываем
навсегда. Ничего не коммитим.** (Возможное отдельное направление — оценка возраста по цепочке
замеров через совместный обратный ход: ошибка 0.4–0.6 дня. Это отдельная фича, не двухфазная
модель; может быть проверена отдельно по вашему запросу.)
