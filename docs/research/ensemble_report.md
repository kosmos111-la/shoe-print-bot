## 3. Вердикт по критериям задачи
- **V1 (усреднение ответов) — подтвердился по формальному критерию: 2.659 < 2.683.**
  Лучше ОБЕИХ одиночных на всех диапазонах: 3-7 −0.024, 3-10 −0.022, 0-2 −0.01 (не упал),
  10-14 −0.02, all −0.019. r02 95% vs 96% — на 1 строку из 94 (сказано честно).
- **Механизм работает:** ответы расходятся (tA≠tB) только в 25 из 267 строк (9%), и именно там
  среднее даёт выигрыш: A=4.160, B=4.000, **V1=3.800** (−0.36/−0.20). На остальных 242 строках
  ответы совпадают — ансамбль ничего не портит.
- **Устойчивость:** 3 случайных сплита по цепям — V1 нигде не хуже одиночных (обычно лучше на
  0.01-0.04): сплит 1: 4.053/2.449, сплит 2: 3.949/2.431, сплит 3: 3.968/2.646 (все/3-7).
- **V2 (пересечение интервалов) — НЕ подтвердился в целом:** лучше только на 10-14 (10.083) и 8+
  (8.659), но хуже на 3-7 (2.695) и 0-2 (0.819). Для внедрения не предлагается.

## 4. Честная оценка величины
Выигрыш V1 мал по абсолютной величине (≈0.02, в пределах шума для n=82), НО: знак устойчив на
всех 4 проверках (сезонный холдаут + 3 случайных сплита) и эффект локализован на расходящихся
строках (−0.2..−0.36), где усреднение принципиально уместно (две независимо калиброванные модели
«спорят» → истина между ними).
