# KN(T) по градусам: форма кривой — отчёт (повторная проверка)

Дата: 2026-11-12. Стенд `analyze_knt2.js`. Модель = старение (коммит 33), база KN=0.60.
Повтор после «немонотонной» проверки по 3 диапазонам: разбивка по градусам (−20..−15 … −2..0),
подбор форм (кубический полином / гаусс / сигмоида), R² и AIC на train, холдаут 2024-25, 0-2,
прямая симуляция. Оптимизировался ТОЛЬКО KN(T).

## ШАГ 1 — KN_факт (медиана Δ/P) по градусам (снежные дни P>0.5, T<0; 542 пары)
| T | n | медиана Δ/P | std |
|---|---|---|---|

| −15..−12 | 32 | 0.000 | 0.85 |
| −12..−10 | 39 | 0.656 | 3.45 |
| −10..−8 | 65 | **1.091** | 0.83 |
| −8..−6 | 118 | 0.493 | 1.72 |
| −6..−4 | 61 | 0.323 | 1.15 |
| −4..−2 | 99 | 0.275 | 0.68 |

**Формы НЕТ**: медианы прыгают (≈0 при −20..−12, пик −10..−8 = 1.09, провал −8..−2 = 0.28-0.49,
подъём −2..0 = 0.90) — ни колокола, ни S-кривой, ни выпуклости. **std превышает медиану в 2-5×
в каждом интервале** — разброс доминирует. «Профиль» из трёх диапазонов (0.70/0.91/0.59) был
усреднением шума.

## ШАГ 2 — Подбор форм (train, чистые пары P≥2, Δреал>0.5; n=235)
| Форма | Параметры | R² | AIC |
|---|---|---|---|
| Кубический | 0.784 −0.118T −0.020T² −0.001T³ | **0.034** | −224.7 |
| Гаусс | A=0.46, μ=−6, σ=1.5, b=0.69 | **0.064** | −232.2 |
| Сигмоида | L=0.25, k=1.2, T0=−8, b=0.70 | **0.022** | −221.9 |

**R² < 0.3 для всех форм → «кривой нет, шум»** (по правилу ОГРАНИЧЕНИЙ). Температура объясняет
2–6% разброса KN_факт. Лучшая AIC у гаусса — но R² всё равно 0.06.

до 100%, MAE 0-2 0.64-0.67; но это не компенсирует ухудшение 3-7/3-10.)

## ШАГ 5 — Прямая симуляция (снежные дни n=574)
Δреал=1.60 | Δмодель: база 2.09, куб 2.83, гаусс 2.75, сигм 2.86.
**Переприбавка НЕ уменьшилась — выросла** (2.09 → 2.75-2.86): подогнанные кривые дают средний
KN ≈ 0.7-0.9 (выше константы 0.60) → ещё больше лишней глубины.

## ШАГ 6 — ВЫВОД
**KN(T) НЕ ПОДТВЕРДИЛОСЬ (повторная проверка по градусам):**
1. Кривой нет: медианы по градусам без паттерна, std ≫ медиана; «немонотонность» трёх диапазонов —
   усреднение шума;
2. R² всех форм 0.02-0.06 (< 0.3) — форма не идентифицируется, сказано явно;
3. На холдауте все формы хуже базы (3.01-3.24 vs 2.71), 0-2 не пострадал (r02 100%);
4. Прямая симуляция: переприбавка 0.48 → 0.7+ (выросла) — KN(T) не лечит снежную переприбавку.

Источник переприбавки на снежных днях (δΔ −0.48) — не температурная зависимость плотности:
средний KN_факт ≈ 0.6-0.9 без формы по T; это уровень самих осадков/событий (P Open-Meteo),
не закон KN(T). Модель НЕ меняется, KN остаётся 0.60, коммит не делается.
Ограничения честно: −20..−15 n=25 (<30 — сказано); R²<0.3 — «кривой нет, шум» (сказано).
