# Итоговый отчёт: физическая модель оседания снега (Шаг 7)

**Модель**: `H(t) = (H0 + k_накоп × A(t)) × f_осед(t, T)` — оседание идёт всегда, новый снег добавляет вес.
Все параметры оценены из данных (никакой оптимизации гиперпараметров).
Отчёты шагов: `phys1_report.txt` (форма), `phys2_report.txt` (40 следов), `phys34_report.txt` (T и наст),
`phys5_report.txt` (обратная функция), `phys6_report.txt` (сравнение с RF), `phys7a_report.txt` (диапазоны).
Графики: `phys1_settling.svg` (кривые оседания), `phys5_pred.svg` (прогноз возраста vs факт).

## Шаг 1. Эталон «След 1» (43 дня, 2022-23)
- Выделено 3 участка без нового снега (осадки ≤ 0.5 мм, T_день ≤ 0): 04–10.02 (n=7), 16–18.02 (n=3), 21–23.02 (n=3).
- Участок 21–23.02 при T = −9.7 **не оседает** (глубина 14.1→14.8) — исключён как не-оседающий.
- Подгонка (пул из 10 точек, нормировка H/H0): **exp** R²=0.610 / AIC=−62.7; **дробно-линейная** R²=0.673 / AIC=−62.5; **логарифм** R²=0.653 / AIC=−61.8.
- **Вывод**: exp и дробно-линейная статистически неразличимы (ΔAIC = 0.2), логарифм хуже.
  На коротких участках обе работают; дробно-линейная физически корректнее на длинных интервалах (плато 1−1/b).
  По результату Шага 5 (инверсия возраста) рабочей выбрана **экспонента**.

## Шаг 2. Проверка на 40 следах 2022-23 (серии ≥ 5 дней)
- Оседающий сегмент найден у 25/40 следов. R² лучшего сегмента: **mean 0.783, медиана 0.898**, min 0.221, max 1.000.
- R² ≥ 0.8: 14 следов; R² ≥ 0.5: 22; R² < 0: 0.
- **Вывод**: форма универсальна (ни одного «анти-оседания»), но **параметр скорости k зависит от следа/сегмента**
  (k от 0.005 до 0.35/день) — причина: свежий снег оседает быстрее (k≈0.07), старый — медленнее (k≈0.02).

## Шаг 3. Температура
- k(T) из сегментов: направление подтверждается качественно — **при T < −10 оседание стоп** (67% сегментов без оседания
  при T<−10 против 33% при −6..−3), при T≈0 идёт. Свидетельство «внутри следа»: След 1, один и тот же снег —
  21–23.02 при T=−11..−18: H не падает; 25–26.02 при T=+2..+1: оседает.
- Подгонка k = k0·exp(c·T): **c = +0.136 1/°C** (теплее ⇒ быстрее, как η ∝ exp(−cT)).
- **Вывод**: зависимость подтверждена качественно; количественно c спутана с возрастом снега (все сегменты свежего снега
  при T≈−4.7, старого при T≈−2.7). В модели оставлена как физическая поправка (на инверсию влияет слабо).

## Шаг 4. Наст (T > 0 и осадки)
- ΔH после наст-дня: медиана **0.00** см, растёт в 43% случаев; после обычного дня: медиана **+0.40**, растёт в 60%.
- **Вывод**: после наст-дней рост/оседание глубины приглушено — слабое свидетельство в пользу «стоп»-правила,
  но наст-дни в данных часто ведут к мокрому снегу и **обвалам глубины** (mean ΔH = −1.95). Жёсткое правило
  «f_осед = 1 при насте» вводить НЕ рекомендую; вместо этого — пометка «день после оттепели: проверьте вручную».

## Шаг 5. Обратная функция возраста (проверка на 2024-25)
- Параметры, оценённые из данных: **H0 = 0.20 см** (медиана замеров возраста 0–2), **k_накоп = 0.50 см/мм**
  (медиана ΔH/осадки по 79 коротким снежным событиям), **k_ref = 0.0264 1/день**, **c = 0.136 1/°C**.
- «След 1» к модели НЕ пригоден: это эталон общего покрова (глубина ~6 см на старте), а не свежий след (H0 = 0.2) —
  подгонка формы выполнена по свежим следам 2022-23+2023-24 (1035 точек), проверка на 2024-25.
- **Обратная функция**: t = argmin |H_obs − (0.2 + 0.5·A(t))·exp(−0.0264·exp(0.136·T(t))·t)|,
  A(t) = сумма осадков за последние t дней, T(t) = средняя T за последние t дней.
- Тест 2024-25 (n=178, те же строки, что у RF): **MAE = 2.29 дня, ±3 дня: 74%, ±7 дней: 98%**.
  На всех 187 строках с глубиной: MAE 4.0 (хуже — там «наст/уничтожен» следы с аномальной глубиной).
- Диапазоны (n=178): точный 51% (0-2: 80%, 3-5: 28%, 6-9: 21%, 10+: 33%); **±1 диапазон: 86%**;
  объединённые 0-2 / 3-9 / 10+: **62%**.
- **Вывод**: формула уверенно отделяет свежий след (0-2) от остального, но 3-5/6-9/10+ между собой разделяет слабо —
  точность формулы (~2.3–4 дня) сравнима с шириной окна. Практически: **0-2 / 3-9 / 10+**.

## Шаг 6. Сравнение формулы с RF (те же 178 строк, 2024-25)
| метрика | RF | формула |
|---|---|---|
| accuracy | 0.702 | 0.607 |
| recall 0-2 | **0.864** | 0.802 |
| precision 0-2 | 0.824 | 0.684 |
| recall 8+ | 0.083 | **0.417** |
- **Вывод**: формула чуть хуже RF по главной метрике (recall 0-2 0.80 vs 0.86, −6 п.п.), но **в 2 раза лучше ловит старые следы (8+)**
  и, главное, даёт то, чего RF не даёт: интерпретируемую физику и **диапазоны возраста**. «Формула не хуже» — с оговоркой:
  для задачи «найти свежий след» RF пока чуть надёжнее; формула оправдана для калькулятора с диапазонами.

## Шаг 7. Финальные формулы для калькулятора
1. **Оседание**: `f_осед(t, T) = exp(−0.0264 · exp(0.136·T) · t)` (альтернатива: дробно-линейная `1 − t'/(1.44 + 3.57·t')`, t' = t·exp(0.136·T), плато ~0.72).
2. **Накопление**: `H0 = 0.20 см`, `k_накоп = 0.50 см/мм` (1 мм осадков добавляет ~0.5 см в следе).
3. **Возраст**: решаем `H_obs = (0.2 + 0.5·A(t)) · exp(−0.0264·exp(0.136·T(t))·t)` численно по истории погоды.
4. **Точность**: MAE 2.3 дня; ±3 дня — 74% случаев; ±7 дней — 98%.
5. **Диапазоны**: свежий 0-2 (recall 0.80), средний 3-9 (62% при объединении), старый 10+; окна 3-5 и 6-9 по отдельности не различимы — выдавать пару окон.
6. **Ограничения**: лес/ветер не учтены (ветер — сильный фактор заметания), нет плотности снега; наст и оттепель
   (после T>0 глубина может рухнуть — формула неприменима); k_накоп сезонно-зависим (2024-25: 0.33 vs 0.50);
   «След 1» — эталон покрова, не свежий след; 2024-25 старые следы неглубокие (1.7 см) — модель и RF их занижают.
7. **Рекомендация**: использовать формулу в калькуляторе (интерпретируемо, без обучения, с диапазонами),
   дополнить ручной проверкой после оттепелей; дособрать данные по месту (лес/поле) и плотности — они добавят
   разделение средних диапазонов. Для максимального recall 0-2 держать RF как второй множитель (0.86 vs 0.80).

**Резюме**: физическая модель построена и работает — главный для поисковика класс (свежий след ≤ 2 дней) формула находит
с recall 0.80 при точности возраста ±3 дня в 74% случаев. RF остаётся чуть точнее по recall 0-2, но не даёт ни физики,
ни диапазонов — для полевого калькулятора формула предпочтительнее.
