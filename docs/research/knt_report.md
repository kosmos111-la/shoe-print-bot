# Калибровка KN(T) на прямых приростах — отчёт

Дата: 2026-11-12. Стенд `analyze_knt.js`. Модель = старение (коммит 33), база KN=0.60.
Оптимизировался ТОЛЬКО KN(T): exp-форма KN0·exp(c·(T+5)) и кусочная (T<−10 / −10..−5 / −5..0).
Таяние (KTAI) не трогалось (отложено, n=18).

## ШАГ 1 — Эмпирическая зависимость KN_факт = Δреал/P (снежные дни P>0.5, T<0)
Пар всего 972, снежных T<0 — 542 (train 445, test 97).

| T | n | KN_факт (гросс) | KN_факт (P≥2, Δреал>0) |
|---|---|---|---|
| < −10 | 96 | 0.702 | 0.669 (n=48 ⚠️<50) |
| −10..−5 | 223 | **0.914** | 0.920 (n=144) |
| −5..0 | 223 | 0.588 | 0.634 (n=120) |

**Зависимость НЕ монотонна** (середина −10..−5 — максимум 0.91, тёплый мороз −5..0 — минимум
0.59). OLS ln(KN_факт)~T (train, n=257): наклон **−0.013** → KN растёт при похолодании —
противоположно гипотезе «мороз → плотнее → меньше см/мм». Данные не дают единого знака.

## ШАГ 2 — Подбор форм по прямой ошибке прироста (train снежные дни, n=445)
- **exp: ЛУЧШИЙ c=0** (= текущая константа, err 2.133); все c≠0 хуже (2.17–2.55) →
  **c_KN не идентифицируется** (сказано честно: MAE не меняется в пользу любой c≠0);
- кусочная: (T<−10)=0.35, (−10..−5)=0.75, (−5..0)=0.35 — err 1.991 (лучше базы 2.133 на ПРЯМОЙ
  ошибке), повторяет немонотонную картину ШАГ 1 (середина высокая, края низкие).

## ШАГ 3-4 — Обратная задача: train и холдаут 2024-25 (база test 3-7 = 2.7073)
| Вариант | TRAIN 3-7 | TEST 3-7 | TEST 3-10 | 0-2 | r02 |
|---|---|---|---|---|---|
| база KN=0.60 | 2.550 | **2.707** | 4.36 | 0.72 | 96 % |
| exp c=0 (=база) | 2.550 | 2.707 | 4.36 | 0.72 | 96 % |
| кусочная (0.35/0.75/0.35) | **3.717** | **3.098** | 4.63 | 0.77 | **89 %** ⚠️ |

**Кусочная KN(T) разрушает обратную задачу**: train 3-7 2.55→3.72, test 2.71→3.10 (хуже порога
2.72), recall 0-2 падает 96%→89% (против правила «0-2 не должны упасть»). Выигрыш кусочной
есть ТОЛЬКО на прямой ошибке прироста (1.991 vs 2.133) — он не переносится в возрастную
дискриминацию (прямой прирост ≠ критерий обратной задачи, которую решает бот).

## ШАГ 5 — Прямая симуляция с KN(T) (снежные дни, n=574)
Δреал=1.60 | Δмодель база=2.09 (δΔ 0.48) | Δмодель exp(c=0)=2.09 (δΔ 0.48) — **не изменилось**
(c=0 ≡ база; лучшая идентифицированная форма = константа).

## ШАГ 6 — ВЫВОД
**KN(T) НЕ ПОДТВЕРДИЛОСЬ**:
1. Эмпирика не монотонна (0.70/0.91/0.59) и по OLS противоположна гипотезе — «плотность снега
   растёт с морозом» данными не подтверждается (середина мороза даже даёт БОЛЬШЕ см/мм, чем
   модель).
2. exp-форма: c не идентифицируется (лучший c=0 = текущий KN).
3. Кусочная форма подгоняется под прямые приросты, но ломает холдаут (3-7 3.10 vs 2.71) и 0-2
   (r02 96→89%) — артефакт прямой ошибки, не физика.
4. Систематическая переприбавка на снежных днях (δΔ 0.48) не объясняется температурной
   зависимостью KN: средний KN_факт ≈ 0.6–0.9 вокруг константы; источник — конкретные события
   (P/плотность отдельных снегопадов), а не единый закон KN(T).

Модель НЕ меняется, коммит не делается. Ограничения честно: <−10 чистая выборка n=48 (<50);
c_KN не идентифицируется — сказано явно; KTAI отложен (n=18).
