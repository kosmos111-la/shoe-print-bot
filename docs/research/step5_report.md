## Рекомендация
- **Вариант B (0-2 / 3-7 / 8+)** — сбалансирован по объёму (381/411/582), все классы ≥ 380;
  исходный вариант A тоже работоспособен (все классы ≥ 205), но классы 2-3 и 0-1 тонковаты;
- классы НЕ разделяются по одной глубине (перекрытие p25-p75 у 3-7 и 8+),
  обязателен контекст осадков (флаг/сумма);
- подгруппа «без нового снега» (флаг=0) в категории 8+ даёт глубина ≈ 0 — это отделяемый
  сигнал «след старше 7 дней»;
- для кривой оседания лучший материал — сезон 2022-23 (41 трек с ≥5 измерениями глубины).
