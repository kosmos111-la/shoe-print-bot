# Итоговый отчёт: полная проверка физических моделей давности следа (скользящие окна 2–10 суток)

**Масштаб:** все 3 сезона, 124 следа с данными >2 дней, 5182 скользящих окна
(каждая пара замеров одного следа с разницей возраста ровно L суток = отдельное измерение).
Параметры фиксированные: k_накоп=0.5 см/мм, k_ref=0.0264 1/день, c=0.136 1/°C, k_тай=0.
Ничего не оптимизировалось.

## ЭТАП 6. «Холодное уплотнение»
Окна L=2–3 с ΔH_obs < −2 см при T < −5°C: **34 случая = 1.9%** всех окон L=2–3 (тёплых обвалов при
T ≥ −5: 126 = 7.2% — в 4 раза чаще).
- **Это 3 эпизода**: 2022-23: 13 случаев, 20–24.02.2023; 2023-24: 17 случаев, 03–07.12.2023
  (тот самый пример: наст 8.1→1.2 при T≈−7…−10°C — уплотнение, а не таяние); 2024-25: 4 случая, 18–20.12.2024.
- Обе модели на этих окнах: MAE ≈ 5.2 см, смещение ≈ +5.2 см — **провал не предсказывается вообще**
  (при T<0 формула только оседает, а пухляк схлопывается). Ошибка ≈ сам размер провала.
- Вывод: холодное уплотнение — реальный феномен (подтверждён настом), но редкий (1.9%) и эпизодический;
  для него нужно отдельное правило (быстрое оседание рыхлого слоя, ~10× быстрее k_ref), данных для
  калибровки мало (34 окна) — честная рекомендация: гипотеза на будущее, а не готовое правило.

## Выводы и рекомендация
1. **Формула жизнеспособна на окнах 2–7 суток** (MAE 2.4–4.3 см); на 8–10 суток точность падает
   (4.4–5.1 см) из-за растущего положительного смещения (переоценка глубины).
2. **Послойная модель даёт преимущество**: лучше на 60% окон и на каждой длине; в обратном поиске
   MAE 4.95 vs 5.34 дня и ±7 дней 86% vs 79%. Особенно полезна в сезоны с оттепелями (2023-24: 78% окон)
   и на коротких окнах 2–3 суток (65%).
3. **Обратный поиск**: надёжен для возраста 0–2 дня (87% попаданий ±3 дня), приемлем для 3–9 дней
   (63%), бесполезен для 10+ дней (глубина насыщается) — это ограничение данных, а не модели.
4. **Холодное уплотнение — проблема, но редкая** (3 эпизода за 3 сезона, 1.9% окон). Обе модели
   его не видят; для калькулятора это означает: в периоды быстрого уплотнения (после сильного снегопада
   при морозе) ошибка может быть 2–5 см.
5. **Рекомендация для калькулятора**: послойная модель (эпохи) — она стабильно точнее; если погода
   доступна только посуточно — базовая формула с эмпирическим интервалом ±3–7 дней; для возраста >10 дней
   калькулятор должен честно говорить «давность неопределима».
6. **Диагностика**: разность «глубина_в_следе − наст» (пик +3.7 см на возрасте ~5 дней, 0 на 0–1 и 9+)
   и ряд наста (рост/обвал) — как признак ловушки и индикатор эпизодов уплотнения.
