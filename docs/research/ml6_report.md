# Итоговый отчёт: baseline-модели давности следа (3 класса: 0-2 / 3-7 / 8+)

Модели реализованы на чистом numpy (sklearn в окружении нет): `ml_basics.py`.
Эксперименты: `ml345_report.txt`, данные: `model_dataset.csv` (осадки_мм — сумма за период).
Графики: `ml4_pdp_depth.svg`, `ml4_pdp_temp.svg`.

## Контекст
- Тест (протокол 1, 2024-25, только строки с полной погодой): **178 строк** — 81/73/24 (0-2/3-7/8+).
- Majority-базлайн (всегда «0-2») на этом тесте: accuracy = 0.455.
- 80 строк без погоды (все 2024-25; 10/4/66 по классам) — **исключены из теста, не импутированы**.

## Шаг 3. Только глубина (Decision Tree, depth=3)
| | acc | recall 0-2 | recall 3-7 | recall 8+ |
|---|---|---|---|---|
| DT глубина-only | 0.596 | 0.765 | 0.466 | 0.417 |

Глубина одна — слабо, но НЕ бесполезно (0.596 > 0.455 majority): свежие следы (малая глубина) частично отделимы.

## Шаг 4. Глубина + погода + сезон + флаг (протокол 1)
| модель | acc | recall 0-2 | precision 0-2 | recall 3-7 | recall 8+ |
|---|---|---|---|---|---|
| LogReg | 0.618 | 0.654 | **0.898** | 0.589 | 0.583 |
| **RandomForest** | **0.702** | **0.864** | 0.824 | 0.726 | 0.083 |
| GradientBoosting | 0.629 | **0.889** | 0.692 | 0.534 | 0.042 |

- **Сигнал есть**: добавление погоды даёт +0.11 accuracy (0.596→0.702) и +0.10 recall 0-2 (0.765→0.864), +0.13 precision 0-2 (0.689→0.824).
- **Recall 0-2 ≥ 0.7 достигнут**: RF 0.864 и GBM 0.889 — главный класс поисковика отделяется хорошо.
- Класс 8+ на тесте 2024-25 проваливается (recall 0.04–0.08): в тесте всего 24 строки 8+, их глубина в 2024-25 аномально мала (1.7 см против ~10 см в других сезонах) — модель обучена на «глубоких» 8+.

## Feature importance (RF, gini)
1. **осадки_мм (сумма за период)** — 0.481 (главный: накапливаются с возрастом, но это физически осмысленный признак);
2. **глубина_см** — 0.251;
3. **температура_avg** — 0.104;
4. ветер_avg — 0.070; флаг_нового_снега — 0.034; сезоны — ~0.03 (в LOSO сезон бесполезен по построению).

PDP (`ml4_pdp_depth.svg`, `ml4_pdp_temp.svg`): P(0-2) падает с ростом глубины, P(8+) растёт;
с ростом температуры P(8+) падает, P(0-2) растёт — направление физически верное.

## Шаг 5. Стабильность (LOSO)
| фолд (test) | LogReg acc / r02 | RF acc / r02 | GBM acc / r02 |
|---|---|---|---|
| 2022-23 | 0.376 / 0.98 | 0.486 / 0.94 | 0.425 / 0.96 |
| 2023-24 | 0.516 / 0.31 | 0.648 / 0.70 | 0.620 / 0.68 |
| 2024-25 | 0.618 / 0.65 | 0.702 / 0.86 | 0.629 / 0.89 |

- **Разброс большой** — модель НЕ стабильна по сезонам (accuracy 0.38–0.70, recall 0-2 0.31–0.98).
- «Выбивается» **не** 2024-25 (на нём accuracy лучшая — 0.70), а **2022-23 как тест** (acc 0.38–0.49):
  модель, обученная без 2022-23, не видела его «глубоких» 8+ (средняя глубина 11.3 см) → recall 8+ 0.15–0.35.
- **Переобучения на 2022-23 нет**: recall 0-2 на тесте 2022-23 = 0.94–0.98 даже без 2022-23 в обучении —
  класс 0-2 отделим по глубине/осадкам независимо от сезона (главное для практики!).
- Самая стабильная — **RF** (recall 0-2: 0.94/0.70/0.86; acc 0.49/0.65/0.70).

## Шаг 6. Выводы
1. **Лучший протокол для recall 0-2**: Протокол 1 (train 2022-23+2023-24 → test 2024-25) с RF или GBM —
   recall 0-2 0.86–0.89; RF дополнительно держит 3-7 (0.73).
2. **Достаточно для поля?** Для класса 0-2 — да (recall ≥ 0.7: 0.86–0.89). Общая точность 0.70 —
   для полевого инструмента маловата: 8+ теряется, 3-7/8+ путаются.
3. **Главные признаки**: осадки за период (0.48), глубина (0.25), температура (0.10).
4. **Ограничения**: нет «места» (лес/открытое) и плотности; 2024-25 слабый (8+ = 24 строки, глубина 1.7 см,
   80 строк без погоды исключены); сезонный сдвиг между зимами велик.
5. **Что дособрать**: место (лес/поле/низина) — дешёвый сильный признак; плотность снега;
   больше замеров 0-2 в 2024-25 (сейчас 81 строка с погодой, 10 потеряны на пропуске погоды);
   регулярные замеры 8+ в 2024-25 (сейчас их почти нет).

**Резюме**: сигнал есть и он практический — свежие следы (0-2 дня) модель находит с recall 0.86–0.89
при точности 0.70 (RF). Для полного решения нужен досбор данных (место, плотность, 2024-25) —
базовый пайплайн (признаки, сплиты по следам, метрики) готов и воспроизводим.
