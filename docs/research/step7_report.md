# Шаг 7. Маркер растений (листы «Растения», «Растения +»)

Маркерная таблица: `step7_plants.csv` (вид | дата_приминания | дата_замера | возраст | состояние).
Сводка: `step7_plants.txt`.

## Что в данных
- **8 видов** растений: Трава, крапива 20 см, заячья капуста, черника, Земленика, Сныть,
  Сныть - тропа, Сныть -тропа 2;
- **200 строк** (25 временных срезов на вид), возраст 0..42 суток, период **02.05.2023 – 26.06.2023**
  (один тёплый сезон, снега нет);
- Состояния — **качественный свободный текст** по частям растения: лист (48 описаний),
  обратная сторона (35), стебель (38). ~60% ячеек пустые, заполнены в основном возрасты 0–3 суток;
- «Растения +» — **данных нет**: лист содержит только две подписи («Светолюбивые», «Теневые»).

## Информативность и корреляция
- **Качественная корреляция с возрастом есть и логична**: серии показывают восстановление —
  «залом/замятие» (0–1 сут) → «расправился/поднялся» (2–7 сут) → «подгнивает/без изменений» (8+ сут);
- **численной корреляции построить нельзя**: состояния — свободный текст без стандартизованной
  шкалы, n крайне мало (4–11 заполненных наблюдений на вид);
- данные **не связаны со снежными следами** (другое явление: восстановление травы после
  приминания), в модель давности следа не входят;
- ценность — как **методологический прототип**: «маркер → давность» по внешним признакам
  с фиксацией дат, аналогично задаче по следам, но неприменимый численно.

## Вывод
Лист растений пригоден только как иллюстрация подхода. Для численной модели давности следа
данных здесь нет (текст, 8 объектов, один сезон). Замечание к протоколу: состояния стоит
кодировать в категориальную шкалу (0 — следов нет … 3 — полное восстановление).
