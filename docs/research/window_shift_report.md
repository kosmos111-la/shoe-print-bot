# Гипотеза «сдвиг окна» (калибровка с 3-го дня) — отчёт

Дата: 2026-11-12. Модель не менялась (`analyze_window_shift.js` — отдельный стенд).
A) честный холдаут: калибровка 2022-23+2023-24 → тест 2024-25. B) in-sample: всё → всё.

## ШАГ 1. Данные 3-7 дней
- A: train 3-7 = **329 строк / 87 следов**, test 2024-25 = 82 / 25.
- B: все = 411 / 112. Возраста 3..7: 95/90/79/72/75 (B), 75/72/64/59/59 (A-train).
- Данных достаточно (>100).

## ШАГ 2. H0_3 (медиана глубины на 3-й день)
- A (train) = **3.50 см**, B (все) = **3.50 см** — **одинаковы** (2024-25 почти не сдвигает
  медиану: n=20). По сезонам: 2022-23 = 4.00, 2023-24 = 3.50, 2024-25 = 3.30.
- По вашему ограничению: H0_3(A) ≈ H0_3(B) → якорь одинаков, A и B — по сути одна настройка.

## ШАГ 3. Калибровка k_ref (c=0.136, KN=0.60 фикс)
| k_ref | A in-fit MAE 3-7 | B in-fit MAE 3-7 |
|---|---|---|
| 0.005 | **2.438** | **2.552** |
| 0.010 | 2.465 | 2.574 |
| 0.0264 | 2.571 | 2.662 |
| 0.035 | 2.802 | 2.852 |
| 0.050 | 2.918 | 2.956 |

Оптимум на краю сетки (0.005 — «почти нет оседания»); тот же паттерн, что в двухфазном
тесте (k_slow → низ). Лучшие: A = 0.005, B = 0.005.

## ШАГ 4. Холдаут A (2024-25, 3-7) — НЕ подтвердилось
| вариант | MAE 3-7 | rcat 3-7 |
|---|---|---|
| текущая модель (k_ref=0.0264, H0=0.5) | **2.72** | 44% |
| сдвиг окна, k_ref=0.0264 | 3.02 | 37% |
| сдвиг окна, k_ref=0.005 | 3.01 | 37% |

**Сдвиг окна УХУДШАЕТ холдаут: 2.72 → 3.01.** Критерий «MAE < 2.72» не выполнен.

## ШАГ 5. In-sample B (все, 3-7)
| вариант | MAE 3-7 | rcat 3-7 |
|---|---|---|
| текущая модель | 2.73 | 48% |
| сдвиг окна, k_ref=0.005 | **2.55** | 46% |

In-sample выигрыш есть (2.73 → 2.55), но он целиком от train-сезонов: 2.44 на train,
а 2024-25 в этой настройке — 3.01 (хуже своего baseline 2.72). **B >> A формально
(2.55 vs 3.01), но 2024-25 не «съедает» потенциал — сдвиг окна ей активно вредит**
(медиана 3-7 глубин 2024-25 = 3.6 против 4.8/5.6 в других сезонах: якорь 3.50 из train
систематически «старит»/«молодит» неверно).

## ШАГ 6. 0-2 не сломаны — даже улучшились (вне ожиданий)
| вариант | recall 0-2 | MAE 0-2 | MAE (все) |
|---|---|---|---|
| текущая модель | 0.798 | 1.27 | 4.78 |
| сдвиг окна (A- или B-конст.) | **0.877** | **0.90** | **4.56** |

Механизм: якорь H0_3=3.5 делает модель «уверенной» в молодости мелких следов —
мелкие строки больше не получают t* ≥ 3. Но это же свойство вредит 3-7 на 2024-25,
где 3-7 следы мелкие (медиана 3.6).

## ШАГ 7. Вывод
1. **A (холдаут): не подтвердилось** — MAE 3-7 2.72 → 3.01 (хуже), rcat 44% → 37%.
2. **B (in-sample): потенциал есть** (3-7: 2.73 → 2.55; бонус 0-2: recall 0.798 → 0.877),
   но он не переносится на 2024-25 — там сдвиг окна активно ухудшает 3-7.
3. H0_3(A) = H0_3(B) = 3.50 — якорь одинаков, «эффект A vs B» отсутствует по построению.
4. k_ref=0.005 (край сетки) — снова паттерн «данным нужно меньше оседания» (как в
   двухфазном тесте), не переносится на холдаут.

**Решение: НЕ внедряем — оставляем текущую модель (k_ref=0.0264, H0=0.5), ничего
не коммитим.** Выигрыш in-sample без переноса на холдаут = аргумент НЕ для внедрения,
а для сбора данных других регионов (план зимы 2026-27): на 2024-25 сдвиг окна
не помогает именно из-за аномально мелких глубин 3-7 этого сезона.
