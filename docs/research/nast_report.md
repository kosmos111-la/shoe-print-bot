# Отчёт: перекалибровка по колонке «наст» (уровень пухляка на насте вне следа)

Колонка найдена и проверена: **наст = значение в строке «ночь» в колонке «След 1» (col10)**, которое реплицировано
по колонкам следов (в 2022-23 зона репликации сдвигается — правило: col10 → репликация ≥3 → cols 43-58).
Серия пользователя подтверждена: **02–06.12.2023: 1.6 → 6.1 → 8.1 → 1.2 → 0.4** (2023-24).

## ШАГ 1. Присоединение наста к наблюдениям
- Ряд наста: 2022-23 — 49 дат (26.01–15.03), 2023-24 — 112 дат (22.11–12.03), 2024-25 — 111 дат (09.12–29.03).
- Присоединён к **1684/1693 наблюдений (99%)** по дате замера → `snow_long_nast.csv` (новый признак `наст_см`).

## ШАГ 2. k_накоп = Δнаст / осадки
| атрибуция | n | k_накоп (медиана) |
|---|---|---|
| осадки только дня0 | 37 | 1.119 см/мм |
| **осадки за окно [д0+д1]** | **50** | **0.453 см/мм** (IQR 0.29–0.66) |

- По сезонам (окно): 2022-23: 0.43, 2023-24: 0.44, 2024-25: 0.52.
- **Вывод: наст ПОДТВЕРЖДАЕТ прежнее k_накоп = 0.5 см/мм, а не заменяет его.** Значение 1.5 — артефакт
  атрибуции: снег 03.12 (9.3 мм) создал рост наста, а делили его на осадки 02.12 (0.6 мм).
- Контроль по примеру: рост 1.6→8.1 за 02–04.12 = 14.9 мм × 0.45 ≈ 6.7 см ✓.

## ШАГ 3. k_тай по обвалам наста при T > 0
- Тёплых обвалов (T>0, Δнаст<0): **n=25**, все с осадками>0.
- **k_тай = 0.50 см/(°C·мм)** (медиана; разброс 0.13–1.14). Термический вариант: 1.25 см/°C-день.
- Применение: модель следа с k_тай=0.5 — MAE(2022-23, 10 следов) = 2.92 vs 2.42 без него; обратный поиск
  2024-25: MAE 4.40 vs 2.15. **Ухудшает** — потому что в тесте 2024-25 осадки при T=+1..+2 — мокрый снег
  (добавляет), а не дождь (плавит), и тёплые обвалы наста происходили вне тестового окна.

## ШАГ 4-5. Пересчёт модели и проверка на 2024-25
| калибровка | прямая 2022-23 MAE | обратный поиск 2024-25 MAE | ±3 | recall 0-2 |
|---|---|---|---|---|
| старая (k_накоп=0.5, k_тай=0) | 2.42 см | 2.15 дн | 80% | 0.818 |
| наст (k_накоп=1.51, k_тай=0.5) | 16.2 см | 3.15 дн | 65% | 1.000* |
| комбо (k_накоп=0.5, k_тай=0.5) | 2.92 см | 4.40 дн | 75% | 0.818 |
\* recall 1.000 — артефакт насыщения: при k_накоп=1.51 почти все возраста дают t*=1 (глубина ≥1.5 см уже в 1 день).

**Вывод ШАГ 5: улучшения НЕТ.** MAE не улучшился ни в одной перекалибровке; recall 0-2 не изменился (0.818).
k_накоп наста = 0.45 подтверждает старую калибровку, k_тай наста переносится на след плохо.

## ШАГ 5 (доп.). Наст как сигнал «ловушки»: глубина_в_следе − наст
- 2022-23: медиана **+5.0 см**, 88% следа > наст; 2023-24: +1.1 см, 62%; 2024-25: 0.0 см, 46%.
- По возрастам (2024-25): 0-1: 0.0; 2: +1.0; 3: +1.95; 4: +1.55; **5: +3.7**; 6-8: +1.7..+2.0; 9+: 0.0.
- «Ловушка работает»: свежий след ≈ наст; на 2–8 день след держит БОЛЬШЕ фона (пик ~5 дн); к 9+ дню
  след сравнивается с фоном. Это грубый индикатор возраста (0-1 или 9+ ⇔ разность ≈0; 2-8 ⇔ разность >1),
  не точная оценка — но бесплатный признак для поисковика.

## ШАГ 6. Пример 03–05.12.2023 (наст 8.1 → 1.2)
- Погода 02–06.12.2023: T = −4, −7, −7, −10, −11 °C; осадки 0.6, 9.3, 5.0, 1.2, 0.2 мм.
- **ВАЖНО: оттепели НЕТ (T ≤ −4°C на всех днях). Обвал 8.1→1.2 при холоде — это НЕ таяние,**
  а **быстрое уплотнение рыхлого слоя** (8 см свежего пухляка 03–04.12 → 1 см 05.12).
- Модель воспроизводит РОСТ: 1.6→8.1 = 14.9 мм × 0.45 ≈ 6.7 см ✓ (H_расч 5.1 → 7.6).
- Обвал модель НЕ воспроизводит (H_расч остаётся 8.1): рыхлый слой уплотняется ~в 10 раз быстрее
  (остаток ~15%/сутки), чем снег в следе (k_ref = 0.0264/сутки). Это отдельный процесс — нужен свой
  коэффициент уплотнения пухляка.
- k_тай=0.5 объясняет только ТЁПЛЫЕ обвалы (2023-11-27: Δ=−7.4 при T=2°C, P=11.6 мм; 2023-12-21:
  Δ=−4.9 при T=1°C, P=5.9 мм).

## Итог и рекомендация
1. **Наст — ценный признак, но НЕ «перекалибровка»: он подтвердил k_накоп ≈ 0.45–0.5** (совпадает с
   трековой калибровкой) и дал k_тай = 0.5 (тёплые обвалы) + открыл, что холодные обвалы — уплотнение.
2. **Применение наст-калибровки к модели следа не улучшило результат** (MAE 2.92/4.40 vs 2.42/2.15) —
   рыхлый слой наста и уплотнённый снег в следе ведут себя по-разному.
3. Рекомендация: оставить k_накоп = 0.5 (теперь подтверждён настом), k_тай = 0 для следа (дождя в тесте нет),
   а **наст использовать как диагностический признак**: разность «в следе − наст» (>1 ⇔ возраст 2–8;
   ≈0 ⇔ 0–1 или 9+) и как калибровочный эталон накопления/таяния для будущих сезонов.
4. Артефакты: `nast_series.csv` (ряд наста), `snow_long_nast.csv` (наблюдения + наст).
