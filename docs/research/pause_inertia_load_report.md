⚠️ n(6+) = 99 ≥ 50 — флаг не нужен. **Гипотеза опровергнута направлением**: «пауза 6+» —
самый ЛЁГКИЙ класс (1.99), а не самый трудный; хуже всех «пауза ≤ 2» (2.84, свежий снегопад).

Прогноз «6+ хуже, MAE > 4» не подтвердился (факт: 1.99).
