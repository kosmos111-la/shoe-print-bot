  MAE 5.13 (глубокие следы недоданы).
- **Расширять возрастную глубину нельзя ни данными (цензура 65-77%), ни моделью (расходится).**

## ВЫВОД
1. **Систематика найдена и учтена: таяние на T≥0.** Единственный механизм из литературы, давший
   холдаут-выигрыш для прямой модели (2.314→2.047), но **порог <2.0 не достигнут** — по критерию
   задачи «не подтвердилось», хотя это лучший результат за весь прямой цикл.
2. **Расширить возрастную глубину нельзя** — данные цензурированы (65-77% за 30 дней), модель
   расходится. Доступно 0-30 дней, ядро точности 0-7.
3. Прочие систематики (birth-смещение 0-2, недодача глубоких 15-30, сезон 2023-24, сдвиг цепей 40%)
   не моделируются без новых данных (место/интенсивность/профиль).

**Предложение (на ваше решение):** (а) зафиксировать melt≈2 в прямой модели как локальный стенд
(test 2.087, физически умеренный) — внедрения в tracker-tool.js нет (это не боевая модель);
(б) попробовать детектор оттепели по T_день из CSV (существующие данные, точнее день-средней);
(в) закрыть прямой цикл. Модель бота, KN=0.60, кандидаты H0=0.75/kh=−0.02 — не тронуты, коммитов нет.

## 6. ПОПЫТКА: детектор оттепели по T_день из CSV + top-таяние (проверено, НЕ ПОДТВЕРДИЛОСЬ)

Стенды `analyze_melt_diary.js`, `analyze_melt_top.js` (только forward, melt на train, test 2024-25).
- T_день корректен: диапазон −24..8 °C, r(T_день, omT) = **0.93** (n=201 дат), покрытие 25% эпох-дней.
- Детекторы: D0 = om эпохный T≥0 (база), D1 = diary T_день>0 (фоллбек om), D2 = union.
  **D1/D2 при любом melt>0 ХУЖЕ** (train 4.949-6.004): union добавляет дни оттепели (1272 vs 1156),
  агрессивный melt перекомпенсирует → детектор по T_день НЕ улучшает (om остаётся лучшим).
- Физически верное **top-таяние** (только верхний слой): слабее (test 2.192 при melt=8) — верхний
  слой тонкий и постоянно обновляется, warm-day переоценка (−3.34) не исправляется.
- **Итог: лучшая прямая модель остаётся density + per-layer melt на эпохах T≥0: test 2.047
  (melt=8) / 2.087 (melt=2).** Порог <2.0 НЕ достигнут; внедрения в бота нет, коммитов нет.
