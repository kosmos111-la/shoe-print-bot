## 4. ВЫВОД: сделали ли всё возможное?
**Да, в пределах данных.** Полное пространство параметров (G0, melt, τ, γ, K, C, g, c, ветер,
форма таяния, детекторы оттепели) перебрано совместно; лучший test **2.021-2.087** (порог <2.0
не достигнут). Остаточная ошибка НЕ настраиваемая:
- **шум места/следа**: 40% цепей со сдвигом |δ|>2 см, sd=4.16 — разные локации/следы смещены,
  без данных о месте это неустранимо;
- **цензура**: 65-77% строк за 30 дней (след <0.5 см) — старше 30 дней сигнала нет;
- **излом day 10-14** — свойство данных (реальная высота падает), модель его не видит;
- для снижения <2.0 нужны НОВЫЕ данные (метаданные места, интенсивность осадков, профиль
  слоёв), а не новые параметры.

**Финал прямой модели (локальный стенд, в бота НЕ вносится):** density G0=0.45, g=1, c=1.5 +
melt=2 (mult, эпохи T≥0) → **test 2.087**, train 4.545. Агрессивный G0=0.4+melt=8 → 2.021
(крайний: один тёплый день почти уничтожает покров — компенсационный, не физический).
