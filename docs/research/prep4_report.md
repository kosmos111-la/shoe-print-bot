# Шаг 4 (подготовка). «суточный» vs «осадки»

Scatter: **`prep4_scatter.svg`**, данные: `prep4_report.txt`.

## Корреляция
| сезон | все следы (n) | только «След 1» (n) |
|---|---|---|
| 2022-23 | 0.867 (49) | **0.893** (10) |
| 2023-24 | 0.404 (172) | **0.949** (112) |
| 2024-25 | 0.791 (44) | **0.858** (36) |
| все | 0.479 (265) | **0.942** (158) |

Значение 0.86–0.95 подтверждается **только для референсного «След 1»** (его «суточный» —
это свежий снег = суточные осадки).

## Где разброс — это НЕ ошибка данных
- У **других следов** «суточный» варьирует по следам в один день: из 272 дней у 13
  значения различаются (максимум — 2024-01-21: 13 разных значений, размах 20.3 мм;
  период 15–22.01.2024 в 2023-24).
- Примеры: суточный=20.4/19.2/17.8/16.0/11.6/8.7 при осадках=0.00.
- Это **занос/накопление снега в конкретном следе** (след-специфичный прирост), а не
  глобальные осадки. Для референса «суточный» чистый; для остальных следов — загрязнён заносом.
- Сдвиг на день: суточный(день) vs осадки_вчера = 0.28 против 0.48 (тот же день) →
  **накопление с предыдущего дня не подтверждается**; связь — в тот же день.

## Вывод для признаков
- Признак осадков — **только «осадки_мм»** (колонка G, одинаковая для всех следов дня).
- «суточный» других следов как признак **не использовать** (след-специфичен, включает занос);
  «суточный» «След 1» использовать нельзя — «След 1» исключён из обучения (шаг 3).
