## 2) Глубина(возраст): mean/p25/p75, разбиение по флагу — ГЛАВНЫЙ РЕЗУЛЬТАТ
| возраст | флаг=0 mean (n) | флаг=1 mean (n) |
|---|---|---|
| 0 | 0.44 (71) | 0.86 (74) |
| 1 | 0.41 (35) | 2.13 (91) |
| 2 | 0.43 (19) | 3.40 (91) |
| 3 | 0.77 (7) | 4.43 (88) |
| 4 | 0.68 (5) | 5.28 (85) |
| 7 | 0.00 (4) | 7.96 (71) |
| 10 | 0.00 (15) | 7.11 (57) |
| 14 | 0.00 (6) | 10.18 (28) |
| 21 | — | 15.38 (9) |

- **флаг=0 (нового снега не было):** глубина ~0.4–0.8 см и **обнуляется к возрасту 7 дней** —
  это чистое оседание/исчезновение рыхлого снега в следе без снегопадов;
- **флаг=1 (был новый снег):** глубина **растёт с возрастом** (0.9 → 4.4 → 8 → 10 → 15) —
  это накопление снега (в основном референс-трек «След 1»); знак зависимости противоположный.

**Значит, глубина сама по себе не отделяет возраст без учёта снегопадов** — модель обязана
использовать осадки/флаг как контекст (что и заложено в постановке задачи).

## 3) Корреляции (Пирсон / Спирмен, парные по непустым, n>=10)
| пара | Пирсон | Спирмен |
|---|---|---|
| глубина ↔ возраст | **0.33** | **0.54** |
| глубина ↔ температура_день | −0.12 | −0.22 |
| глубина ↔ осадки_мм | 0.15 | 0.21 |
| глубина ↔ суточный_мм | 0.30 | 0.37 |
| суточный_мм ↔ осадки_мм | **0.75** | **0.85** |
| осадки_мм ↔ влажность | 0.35 | 0.43 |
| температура_день ↔ температура_ночь | 0.84 | 0.80 |

- Подтверждено: «суточный» ≈ осадки (0.75/0.85) — дублирующая колонка;
- глубина ↔ возраст слабо-положительная (из-за накопления), не монотонная;
- температура и влажность — слабые сигналы.

## 4) Δглубина/сутки по возрасту (только флаг=0), 89 пар замеров
| возраст начала | n | средний Δ, см/сутки |
|---|---|---|
| 0–1 | 54 | −0.017 |
| 2–3 | 11 | +0.018 |
| 4–5 | 3 | +0.033 |

Оседание без снега очень медленное (≈ −0.02 см/сутки) и заканчивается обнулением к ~7 дню —
это слабый сигнал для разделения 1–7 дней и сильный для «>7 дней» (глубина ≈ 0).
