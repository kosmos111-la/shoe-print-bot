## Как работает `/calc_snow_age`

1. **Местоположение** → **дата пропажи** → **3–5 замеров глубины следа (см)** (новый шаг в `main.js`).
2. `calculateSnowAge(coordinates, disappearanceTime, { depths })` в `index.js`:
   - `season` выводится из даты (ноябрь–апрель → сезон дневника, иначе — нет);
   - без глубин → `«❌ Нужно 3–5 замеров глубины по следу (см)…»`;
   - сначала `tracker.estimateChain(season, date, depths, 'auto')` по эпохам **дневника**;
   - если дневник даёт `«недостаточно данных»` (вне дат дневника или другой район) и есть координаты —
     адаптер `weatherService.getEpochs(lat, lon, date−30, date)` (Open-Meteo) и повторный расчёт;
   - ответ: `formatForBot` (📍 глубина/разброс, 🎯 давность, 🧊 наст по архиву, ⚠️ предупреждения).
3. Ответ — строка; отправляется как текст с `parse_mode: 'HTML'`.

### Модель (сжато)

Послойная «снежная колонна»: свежий след = начальный слой `H0`; снегопады добавляют слои
`h = KN·P`; каждый слой уплотняется по закону `h *= exp(−KREF·exp(C·T)·Δt)` на каждую эпоху
(`Δt = 0.25` сут); наст (оттепель T>0 с осадками → заморозка T<0) останавливает уплотнение
слоёв ниже корки. Давность — решение обратной задачи `t* = argmin |H_прогноз(D−t → D) − H_замер|`.
Патчи «не знаю»: `t* > 10` сут / интервал шире 7 сут → «неопределима»; `σ > 2` сут → «диапазон»;
история < 10 сут → «недостаточно данных»; резкий снегопад (P>5 при T<−5 за 3 дня) и оттепель/дождь
в истории → предупреждения. Цепочка: минимум по 3–5 замерам, разброс > 3 см → «след неравномерный».

### Калибровка и точность (коммит 8, эпохи Open-Meteo/ERA5, все сезоны n=1374)

| Параметр | Значение | Смысл |
|---|---|---|
| `KREF` (k_ref) | 0.0264 1/сут | скорость оседания при 0 °C |
| `C` (c) | 0.136 1/°C | температурная чувствительность (×2 на ~5 °C) |
| `KN` (k_накоп) | 0.60 см/мм | прирост глубины на единицу осадков |
| `H0` | 0.50 см | глубина свежего следа |
| `KTAI` (k_тай) | 0.0 | снятие слоёв дождём (не активирован) |

Метрики (обратный поиск, KN=0.60/H0=0.50): MAE **4.78 сут**, ±3 сут **64%**, ±7 сут **82%**,
recall 0–2 сут **0.798**, accuracy **0.624**. По классам: **0–2 сут** (n=381): MAE 1.27, ±3 — 92%,
±7 — 98%, recall 80%; **3–7 сут** (n=411): MAE 2.73, ±3 — 67%; **8+ сут** (n=582): MAE 8.53, ±3 — 43%.
2024-25 (n=267): recall 0–2 **0.926** (почасовые эпохи; с калибровкой коммита 8 — 0.957).
Научное обоснование и полные метрики — в `docs/snow-age-model.md`.

## Как работает `/calc_weather`

Одно текстовое сообщение вместо трёх тяжёлых, порядок блоков строго:

1. ⚠️ **ШТУРМОВОЕ ПРЕДУПРЕЖДЕНИЕ** (если есть): ветер > 10 м/с, сильный снегопад,
   ледяной дождь, резкое падение T > 5°C (вчера → сейчас и/или день → ночь);
2. 🌡️ **Сводка:** сейчас (ощущается), ветер, видимость, риск для следов
   (наст: есть/нет по оттепелям за 3 дня; занос: высокий/низкий по ветру + снегу);
3. 👕 **Слои одежды по системе ВКПО (8 слоёв)** — `getClothingLayers(temp, wind, precip)`;
4. 📅 **Детали** (история 7 дней + прогноз 2 дня) — в свёрнутом
   `<blockquote expandable>`.

График отправляется **отдельным сообщением** (подпись короткая), текст идёт ПЕРВЫМ.

### График (`weather-graph.js`, коммиты 28–29)

Полотно **1800×1200**, тёмная тема. Элементы:

- **линия температуры — прямая полилиния** через все точки (утро/день/вечер/ночь каждого дня),
  **без сглаживания** (`bezierCurveTo` убран — «хвосты» исчезли); толщина **15 px**,
  `lineJoin/lineCap: round` (нет «шипов»); градиент цвета по температуре;
- **значения на графике**: над каждой точкой — `N°` (температура), над столбцами осадков — `N мм`
  (округление: ≥1 мм — целое, <1 мм — 1 знак);
- столбцы **осадков** (по 4 слота суток; снег — белый/голубой, дождь — голубой), слой **снега**,
  полоса **облачности**, затемнение **ночи** по реальным восходу/закату, чередующиеся **полосы дней**,
  разделители «Утро/День/Вечер», подписи дней;
- **разделитель «История→Прогноз» удалён** (`drawSeparator` — мёртвый код, вызов снят);
- шапка: «🌤️ Погода: ЛОКАЦИЯ» + «Актуально на … | История 7 дней + прогноз 2 дня | 4 точки в сутки».

Проверено: 18/18 тестов графика, погода 74/74, tracker 137/137, smoke OK.

## Сбор данных для перекалибровки (зима 2026–27)

Цель — перекалибровать `KREF, C, KN (k_накоп)` под другие регионы (Новосибирск, Урал) и уточнить
для Подмосковья. Инструменты (вне репозитория, генерируются скриптами):

- **`calibration_table.xlsx`** — полевой дневник в формате «таблица глубин»: блок на след
  (След-01…След-06), столбцы = дни (0 день…23 день), строки = параметры (дата, осадки в см,
  темп. ночью/днём, давление, **глубина следа**, **след виден (да/нет/—)**, **глубина снега
  в лесу**, наст, след в снегу, примечание); листы Инструкция / Ввод / Прогресс / Сводка;
  выпадающие списки, подсветка обязательных, шкала 30 замеров (день × след) = 100%.
- **Цензурированные наблюдения**: если след пропал/заметён — в строке «след виден» ставится
  «нет», глубина = 0. Это **не** «свежий след с глубиной 0», а цензурированное наблюдение
  «возраст ≥ N дней» (проверено: на 2024-25 73% замеров 8+ записаны как 0 — модель ошибочно
  отвечала «0-2 дня»; с флагом такие строки пойдут на специальную обработку при калибровке).
  Сводка считает такие строки отдельно («Замеров „след не виден“»).
- **`export_calibration.py`** → **`calibration_export.csv`** (long: одна строка = замер след × день,
  utf-8 BOM, `,`; колонка «След виден»; строки «не виден» экспортируются даже без глубины).
- **Второй визит к тому же следу** (`estimateAgeJoint`, коммит 32): если поисковик вернулся к тому
  же следу через 2–5 дней и указал дату1+H1 первого визита — бот оценивает давность по **двум
  замерам** (совместный обратный ход, возраст на дату2 `t ≥ L`). Проверено на 2024-25 (модель
  со старением, коммит 33): MAE 3-7 ≈ **1.04–1.70** для интервалов 2–4 дня (против 2.55–2.76
  построчно), при интервалах 5–7 суток — **0.81–1.49**; recall 0-2 на холдауте 86%→82% (n=22,
  одна строка — в пределах шума). В «Сводке» калибровочной таблицы добавлена строка «Второй
  визит к тому же следу (дата1, H1)» для сбора таких данных.
- **Старение** (`AGING_TAU=3.0`, `AGING_GAMMA=2.0`, коммит 33): скорость оседания слоя умножается
  на `S(age) = 1/(1+(age/τ)^γ)` — старый снег оседает медленнее. Подтверждено на двух холдаутах:
  2023-24 (чистый) 3-7 2.82→2.73, 3-10 3.36→3.27; случайный по следам (seed 42) 3-7 2.72→2.66,
  3-10 3.71→3.55, MAE 3.20→2.92; recall 0-2 не упал. Бэкап до правки: `tracker-tool_backup_commit33.js`.
- Минимум **20–30 замеров на регион**; затем — перебор констант по минимуму MAE (как при
  коммите 8) и обновление `tracker-tool.js` (резервная калибровка — в `tracker-tool_backup.json`).

## Честные оговорки

- Модель калибрована на **эпохах дневника** (конкретный район, сезоны 2022–25) и перекалибрована
  под **Open-Meteo/ERA5** (коммит 8). Для произвольных координат эпохи Open-Meteo — адаптер;
  результат помечается предупреждениями.
- Класс 10+ дней (глубина насыщается) может дать уверенное, но неверное число; защита —
  патчи «неопределима» и предупреждение «проверьте вручную».
- Ветер (заметание/намет) не в модели — ловится разбросом замеров > 3 см; плотность снега
  не учитывается явно (входит в KN).
